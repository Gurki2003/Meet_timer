# Until We Meet Again ♥️

A romantic, responsive reunion countdown built with plain HTML, CSS and JavaScript.

## Countdown target

**29 December 2026 at 1:00 AM IST** (`2026-12-29T01:00:00+05:30`).

The target includes the IST offset, so the countdown remains correct for visitors in other time zones.

## Run locally

Open `index.html` in your browser. No build tools or dependencies are required.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `until-we-meet-again`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. Your site will be available at:
   `https://YOUR-USERNAME.github.io/until-we-meet-again/`

## Personalize the love note

Edit the text inside the `<div class="letter" id="letter">` section in `index.html`.

## Change the countdown date

Edit the `target` line in `script.js`. Keep the timezone offset explicit. For IST, use `+05:30`.
